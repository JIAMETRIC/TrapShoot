I wrote the Mac instructions to MAC-AUTONOMOUS-RUN.md in the project root: MAC-AUTONOMOUS-RUN.md.

What you do on the MacBook

Once (details in docs/mac-setup.md)

  1. Install Xcode 26.3 or newer from the App Store and open it once.
  2. In Terminal: 
    sudo xcode-select -s /Applications/Xcode.app
xcrun --find mcpbridge
brew install node
    The last command must print a path.
  3. In Xcode: Settings → Intelligence → Model Context Protocol → Allow external agents to use Xcode tools (on).
  4. Sign in to your Apple Developer account in Xcode → Settings → Accounts. Needed only for Phase 8.

Each session

  1. Get the code: 
    git clone https://github.com/JIAMETRIC/TrapShooterPro.git
cd TrapShooterPro
git pull
    If the folder already exists, skip the clone and run only git pull.
  2. Open TrapShooterPro.xcodeproj in Xcode and leave it open. The Xcode bridge needs it.
  3. Open the TrapShooterPro folder in Claude Desktop (Code tab) and start a new session.
  4. Paste the line: "Read MAC-AUTONOMOUS-RUN.md and carry it out. Stop only where it says to stop."

What Claude does on its own

It runs the mac-build stages in order, using the agents the skill names. It then checks the phases against the Mac and records the results in docs/mac-sessions/. It makes local commits only.

Committing yourself

The four proprietary folders are now in .gitignore, so Git ignores them. I checked git status and they don’t appear in it. Run these in the project folder:

git status --short
git add .gitignore MAC-AUTONOMOUS-RUN.md TrapShooterPro.html guides.html skills.html agents.html phases.html mac-run.html .claude/skills/claude-api .claude/skills/skill-creator
git commit -m "Add the Guides, MacBook, Skills, Agents and Phases pages"
git push origin main

claude-api and skill-creator are Apache 2.0, so they can go to GitHub. The Mac will not get docx, pdf, pptx or xlsx from GitHub, so you’ll need to copy them over by hand.
