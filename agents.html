Short answer: 39 skills and 13 agents, and they guide the 10 phases (0–9) mainly through the Mac workflow.

2. Agents (13)

An agent is a helper that Claude starts for one job. It gets its own instructions, its own tools and a fresh context, and it returns a report. Seven agents are written for this project and their files are in the repository, so their links below open. The other six come with Claude Code and have no file here.

TrapShooterPro agents (7)

Project · Mac · stage 0

mac-preflight

Checks that the Mac can build, test and run the app: Xcode, simulators, Node, the MCP servers, git state, disk space and signing. It explains every WARN or FAIL with the exact command that fixes it. It is read-only and never changes the machine. Use it at the start of a Mac session, or when a build fails for an environment reason.

.claude/agents/mac-preflight.md
Project · Mac · stage 2

swift-builder

Fixes compile errors in one package, or in the app target, until it builds. Then it runs that package's tests once. It works inside the project's rules: no changes to detector logic, no fixture regeneration, no format changes, and design tokens only. The packages are fixed in dependency order, from TrapCore to the app.

.claude/agents/swift-builder.md
Project · Mac · stage 3

sim-tester

Runs one package's tests in the simulator and decides, test by test, whether the Swift or the test is wrong. Golden tests always mean the Swift is wrong. A test that needs a microphone, network or device is skipped with a stated reason, never deleted. It reports the final test output.

.claude/agents/sim-tester.md
Project · Mac · stage 4

app-verifier

Launches the built app in demo mode on the iPhone and iPad simulators. It takes every section in light and dark, scans the launch logs for crashes and TrapLog errors, and checks each screenshot against the design system and the Olympic Trap facts. It returns a table and fixes nothing.

.claude/agents/app-verifier.md
Project · Mac · stage 6

design-reviewer

Renders the TrapDesign previews in light and dark through Xcode's bridge and audits them against the design system: tokens, contrast, 44 pt targets, Dynamic Type and Reduce Motion. It closes the "Design preview rendered light and dark" item in the progress file. It needs Xcode open with the project.

.claude/agents/design-reviewer.md
Project · Mac · stage 7

progress-scribe

Writes the record of a Mac session under docs/mac-sessions/ and updates the rows in docs/progress.md to match what was verified, and nothing more. It edits only those two places and never commits.

.claude/agents/progress-scribe.md
Project · Phase 9

support-triage

Reads one support bundle from a shooter, with any MetricKit payloads. It returns the device, build, audio line and storage, the error lines from the log, the numbers against the Phase 9 targets, a suggested reply and a suggested engineering task. It is read-only and sends nothing.

.claude/agents/support-triage.md
