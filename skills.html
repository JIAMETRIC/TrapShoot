Short answer: 39 skills and 13 agents, and they guide the 10 phases (0–9) mainly through the Mac workflow.

1. Skills (39)

A skill is a set of instructions Claude follows for one kind of task. Six of them are written for this project. Five of those are in the repository, so their files open from the links below. The other 33 are built into Claude Code or its plugins, so there is no file on this machine to open.

TrapShooterPro project skills (6)

Project · Mac

mac-build

Builds, tests and runs TrapShooterPro on a Mac in eight fixed stages: preflight, the whole CI pipeline run locally, compile fixes through swift-builder, test triage through sim-tester, a demo run with screenshots through app-verifier, an XcodeBuildMCP smoke test, the design preview through design-reviewer, and a session record through progress-scribe. Use it at the start of any Mac session. On Windows it stops at preflight.

.claude/skills/mac-build/SKILL.md
Project · Mac + iPhone

mac-device

Runs the app on the owner's iPhone from the Mac and works through the eighteen-row device checklist that the simulator cannot cover: the DJI Mic Mini 2 receiver, plug and unplug, phone call interruption, Low Power Mode, the one-hour battery test, the 2,000-round list speed, backup, reinstall and restore, kill-and-resume, VoiceOver and the scorecard PDF. Only a passing row can change a ⏳ iPhone line in docs/progress.md. The owner must be present with the receiver.

.claude/skills/mac-device/SKILL.md
Project · Mac + Apple account

mac-release

Archives the app, uploads it to TestFlight, tags the build and prepares the App Store submission material. It first checks that today's mac-build passed on the current commit with a clean working tree, and that the detector regression set ran on the Release configuration. Build numbers cannot be reused, so every signing, upload or tag step waits for the owner's yes.

.claude/skills/mac-release/SKILL.md
Project · any machine

detector-fixtures

Turns the owner's range videos and microphone tests into regression fixtures: a mono 48 kHz audio file plus a JSON file of expected call-to-shot times. It runs the regression set through DetectorRegressionTests. Use it before any change near AudioDetector.swift, which CLAUDE.md rule 1 requires. Building fixtures works on Windows with ffmpeg; running the set needs the Mac.

.claude/skills/detector-fixtures/SKILL.md
Project · Phase 9

operate

Runs the app after release, with no server. The weekly triage reads App Store Connect crashes and reviews and support bundles, and checks the results against fixed targets: crash-free sessions above 99.5 %, cold launch p95 under 400 ms, and timer accuracy within 7 ms. It also covers the per-iOS-beta run, the quarterly security review, the yearly minimum-iOS decision, and the deferred options such as iCloud sync.

.claude/skills/operate/SKILL.md
Project · not used here

responsive-screens

Lays out React Native or Expo screens for phones and tablets with a Three-Slot method. This app is native SwiftUI, so the skill does not apply to it. It is listed for completeness.
