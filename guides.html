3. Phases

Phase Name Status Guided by
0 Discovery, architecture, decisions done Docs only
1 Foundation, tooling, tokens done (design preview not rendered) mac-preflight, design-reviewer, CI
2 Pure domain core done mac-build stages 1–3, swift-builder, sim-tester
3 Local store and repositories done (2,000-round timing on device pending) sim-tester, progress-scribe
4 Shot timer engine device verification pending detector-fixtures, mac-device
5 Record and Timer screens next app-verifier, design-reviewer, mac-device
6 Rounds, Analysis, Schemes, exporters after 5 app-verifier, mac-build
7 Settings, data, platform behaviour after 6 mac-device, code-review
8 Release and App Store after 7 mac-release
9 Operate and iterate ongoing operate, support-triage, security-review

Most of these are Mac-only. On this Windows machine, mac-build stops at preflight, so the device and simulator gates (phases 4 and 5 onward) cannot be verified from here. The Windows-side work is limited to code and reasoning, and the detector must not change without a fixture regression run (CLAUDE.md rule 1).
