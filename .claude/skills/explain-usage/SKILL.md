# Explain usage (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Get the session's token totals by input, output and cached.
2. Find the three largest sources, such as long file reads or repeated searches.
3. Draw one simple bar chart of the totals by source.
4. Explain it in plain words, with one suggestion for using fewer tokens next time.
