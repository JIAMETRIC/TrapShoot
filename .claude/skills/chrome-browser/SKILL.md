# Chrome browser (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Load the browser tools once, then list the open tabs before opening anything.
2. Work in a new tab unless the user names an existing one.
3. Ask before submitting forms, buying, sending messages or changing account settings.
4. Use the console and network logs only to debug a page the user asked about.
5. Stop and ask when a page needs a password or a verification code.
