# Run (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Look for the project's run instructions in the README or docs first.
2. Start the app with the documented command, in the background if it does not stop.
3. Check the change in the running app and read the log for errors.
4. Report what you saw, and stop the app when done.
