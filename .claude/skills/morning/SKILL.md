# Morning brief (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Collect only what the user has connected: calendar, tasks and messages.
2. Sort by time. Put the first meeting and any deadline today at the top.
3. Keep it to one screen. Do not send anything.
4. Ask before setting up a recurring task.
