# Keybindings help (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Read the current keybindings file, if there is one.
2. Check that the new key is not already used.
3. Add or change one binding at a time, keeping the JSON valid.
4. Tell the user how to reload and test the binding.
