# Docs (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Agree the title and the audience with the user.
2. Write the headings first, then fill in each section.
3. Keep the summary at the top and the detail below it.
4. Link every source. Mark anything unverified as unverified.
5. Give the user the link to the finished document, and a one-line summary of it.
