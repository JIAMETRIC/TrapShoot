# Workflow authoring (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Confirm the user asked for a workflow. Do not start one on your own.
2. Keep the script small: one phase per step, and a clear result for each.
3. Name each agent step, so progress is easy to follow.
4. Show the script to the user before running it.
