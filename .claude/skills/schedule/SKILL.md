# Schedule (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Confirm the task, the schedule and the time zone with the user.
2. Write a complete prompt that the agent can run without asking questions.
3. Create the schedule only after the user agrees.
4. List the schedules when asked, and say how to stop one.
