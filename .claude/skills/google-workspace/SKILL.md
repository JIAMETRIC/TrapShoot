# Google Workspace (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Read the file before changing it. Identify the exact section, cell range or slide.
2. Make the smallest change that does the job.
3. Do not rename, move or delete a file without the user's confirmation.
4. Read the file again after the change and report what changed.
