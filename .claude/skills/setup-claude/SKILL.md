# Setup Claude (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Ask the user's role and the tools they use each day.
2. Propose the plugins that match, and ask before installing each one.
3. Connect one tool at a time, and confirm each connection works.
4. Run one small task with one skill to show how it works.
5. Summarise what is installed and what is still to do.
