# Deep research (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Split the question into three to six sub-questions and write them down.
2. Search each one. Prefer primary sources. Record the URL and date of each source.
3. Cross-check any figure that matters with a second source.
4. Write the report: findings first, then evidence, then open questions.
5. Cite every claim with a link. Say where sources disagree.
