# Built-in browser (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Open the URL in the browser pane. Prefer reading the page as text over screenshots.
2. Report what the page says, with the URL, and say when a page could not be opened.
3. Ask before submitting any form, signing in, or accepting cookies or terms.
4. Never sign out or change account settings. Treat sign-ins as the user's.
5. If a site is refused, say so and move on.
