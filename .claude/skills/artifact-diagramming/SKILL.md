# Artifact diagramming (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Draw a diagram only when a list or table cannot show the relationship.
2. Use one box per thing, and label each arrow with what it carries.
3. Draw the SVG with a viewBox, so it scales to phone width.
4. Use the colour tokens for fills and strokes, so both themes work.
5. Check that every label is readable at phone width.
