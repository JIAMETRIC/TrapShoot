# Dataviz (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Choose the chart from the question: comparison uses bars, change over time uses lines, parts of a whole use a few slices at most.
2. Use one colour per series, and a colour set that still works in greyscale.
3. Label the axes and the units. Start bar charts at zero.
4. Check contrast of text and marks in both light and dark modes.
5. Give every chart a one-line takeaway title.
