# Computer use (our version)

This is our own version of the built-in skill of the same name. It is not the app's file.

1. Take a screenshot first and confirm which app is in front.
2. Act one step at a time and check the screenshot after each step.
3. Ask before any irreversible action: send, submit, pay, delete, or change a setting.
4. Do not enter passwords, card numbers or codes. Ask the user to do it.
5. Stop when the task is done or when the screen does not match what was expected.
