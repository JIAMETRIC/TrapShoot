# TrapShoot — Support

**Contact**: jiametric@gmail.com. Please attach the file from **Settings → About → Send diagnostics**.

## Common questions

- **The audio check line says NO AUDIO.** Unplug and replug the DJI Mic Mini 2 receiver, switch the transmitter off
  and on, then Stop and Start timer.
- **The timer does not start.** Start the round on Record first (range name, field, sky, temperature, humidity), then
  Start timer. Allow the microphone in Settings → TrapShoot if it was declined.
- **A clay did not come.** Tap NO TARGET: the target keeps its number and station, and the timer listens again.
- **Moving from the 7.x app.** Export your rounds as JSON, then Settings → Data → Restore or import a backup. Rounds you
  already have are never replaced.
- **Backups.** Settings → Data → Back up all rounds saves one file to Files or iCloud Drive.
